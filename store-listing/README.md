# Chrome Web Store listing assets

Generated by `npm run store-assets` (see `scripts/generate-store-assets.mjs`).

| File | Size | Use |
|------|------|-----|
| `store-icon-128.png` | 128×128 | Store icon |
| `promo-small-440x280.png` | 440×280 | Small promo tile |
| `promo-marquee-1400x560.png` | 1400×560 | Marquee promo tile |
| `screenshot-*.jpg` | 1280×800 | Store screenshots (up to 5) |

Brand gradient matches [hiz.al/pwd](https://hiz.al/pwd) (`#283c86` → `#401570` on `#121018`). The store icon is resized from the PWA `icon-512.png` (`purpose: any`, square artwork). Promo tiles center that icon with 20% padding on the shortest side.
